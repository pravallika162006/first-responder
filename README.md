# First Responder Web Application 🚑

## 📌 Description
The **First Responder Web Application** is a web-based project designed to provide quick assistance during emergency situations by enabling fast access to essential information and actions.

## 🎯 Objective
To create a simple and user-friendly interface that helps users respond effectively during emergencies.

## 🛠️ Technologies Used
- HTML  
- CSS  
- JavaScript  

## 🚀 Features
- Responsive user interface  
- Easy navigation  
- Emergency-focused functionality  
- Lightweight and fast  

## 📂 Project Structure

first-responder/
│── index.html
│── style.css
│── script.js

## 🖥️ How to Run
1. Download or clone the repository  
2. Open `index.html` in any web browser
